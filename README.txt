Сайт «нежно» — учебный HTML-прототип.

Как открыть:
1. Распакуйте архив.
2. Откройте index.html в браузере.
3. Остальные страницы связаны через верхнее меню и карточки.

Файлы:
- index.html — главная страница
- theory.html — теория ментального здоровья (тематические ссылки-заглушки)
- specialists.html — демонстрационная форма подбора специалиста
- help.html — страница экстренной психологической помощи без реального номера
- forum.html — тематические разделы форума
- styles.css — общие стили и палитра

Важно:
Это учебный прототип. Форма подбора не отправляет данные и не ищет реальных специалистов.
Форум не подключён к базе данных и не поддерживает публикации.
Контакты экстренной помощи намеренно оставлены незаполненными.
Для реального запуска потребуются проверка специалистов, юридическая проверка,
защита персональных данных, модерация и проверенные контакты служб помощи.
